# FireRed Codex

Guia completo de **Pokémon FireRed & LeafGreen**: Pokédex da Geração III, golpes, rotas com taxa real de encontro, IV/EV e naturezas, montador de times, lendários e treinadores.

🔗 **Site:** https://jhon-catanante.github.io/firered-codex/

## Funcionalidades
- **Pokédex (386)** com status, tipos e habilidades da Geração III, build recomendada, ranking de naturezas e todos os golpes
- **Rotas**: chance de encontro por área e método, com exclusivas de cada versão
- **Treino**: melhores lugares para EVs, tabela de naturezas e calculadora de status
- **Times**: times prontos e montador com análise de fraquezas
- **Lendários**: onde capturar e chance real por Ultra Ball (fórmula da Gen 3)
- **Treinadores**: times exatos de ginásios, Elite Four e rival, extraídos do código do jogo

## Dados
- [PokéAPI](https://github.com/PokeAPI/pokeapi) (CSV), corrigido para a Geração III
- [pret/pokefirered](https://github.com/pret/pokefirered) para os times de treinadores

O site é um único `index.html`, sem build. Os scripts em `scripts/` regeram os dados e montam o HTML a partir de `scripts/template.html`.

## Deploy
Todo push na `main` publica automaticamente no GitHub Pages (`.github/workflows/pages.yml`).
